# PlacementOps Starter Repo

This is an intentionally minimal starter. You may use it or build your own.

## Run

```bash
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Existing endpoints
- `GET /api/health`
- `GET /api/interviews`
- `GET /api/interviews/<interview_id>`
- `GET /api/actions`
- `POST /api/actions`

The app does not include a finished operational solution. Your job is to decide and build the thin slice.
