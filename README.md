# PlacementOps Class 11 Starter Pack

## Theme
A live FDE engagement simulation: start from an ambiguous placement-day problem and build a narrow end-to-end operational solution.

## Your mission
Turn the client problem into a small demonstrable product slice. The goal is not to build a platform. The goal is to show one complete workflow: a placement coordinator can identify a candidate/interview needing attention, review evidence, record one action, and see that action reflected.

## Suggested flow
1. Read `docs/problem_statement.md`.
2. Use `docs/client_discovery_qna.md` to answer discovery questions. Do not read it as a solution document; use it as client evidence.
3. Inspect `data/` and decide what is reliable, incomplete, or ambiguous.
4. Fill the templates in `templates/`.
5. Use `starter_repo/` only if you want a minimal app skeleton. You may also build your own.
6. Prepare a 2-minute demo: problem -> user -> workflow -> action -> evidence -> what you intentionally did not build.

## Data note
The dataset is intentionally small and realistic. Some truths must be derived. Some are unavailable. Do not invent missing operational facts.
